Welcome to my corner of the internet. This site is built with [Astro](https://astro.build), loads almost no JavaScript, and is hosted on GitHub Pages.

## What to expect

I'll write about what I build and learn: agentic AI, voice agents, and what I learn along the way.

## Adding a post

Create a new Markdown file in `src/content/blog/` with this frontmatter:

```md
---
title: My post
description: One sentence summary.
date: 2026-11-02
tags: [topic]
---
```

Push to `main` and the site rebuilds automatically.
